A program that writes one commit message for a bug fix that made everything worse:

> fix: infinite loop by adding a second loop to cancel it out

The fix is the bug, twice over. `main.py` (Python 3.13, standard library only) writes that single 59-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, so both grading runs write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
